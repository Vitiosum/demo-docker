Why Docker here

Native runtimes give you the system tools Clever Cloud installs for you. This app wants its own: an exact ImageMagick build, its coders, a caption font and a locked security policy.

The Dockerfile pins that whole system layer, so the darkroom on a laptop and the one on Clever Cloud are the same image.
